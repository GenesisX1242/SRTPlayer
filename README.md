# SRT Player

Version: 1.1.0

SRT Player 是一款离线外部字幕显示工具，用于独立加载和播放 .srt 字幕文件，对于深造播放器这类加密播放软件可以提供额外的字幕（前提是制作好了字幕文件.srt）。

## 安装

a.完整版运行：

```text
SRTPlayer-Setup-1.0.0
```

安装时可自定义目录。安装后可在 Windows“已安装的应用”中卸载，也可运行安装目录里的：

```text
uninstall.exe
```


b.便携版运行：

解压

```text
SRTPlayer-Portable-1.0.0.zip
```

无需安装，无需管理员权限，不写入 Windows 卸载列表，不创建开始菜单，不创建桌面快捷方式，可以放 U 盘里运行
删除整个文件夹即可卸载。

## 使用

将 `.srt` 文件直接拖入字幕窗口，或者快捷键Ctrl+Alt+O添加文件，或者右键选择打开.srt文件。

- `Space`：播放 / 暂停
- 鼠标滚轮：调整字幕大小
- 拖动窗口边缘：调整窗口大小
- 鼠标移入窗口：显示进度条和控制按钮
- 拖动进度条：调整字幕位置

## 默认快捷键

| 功能 | 快捷键 | 参数 |
|---|---|---:|
| 播放/暂停 | `Space` | |
| 快进 | `Shift+Right` | `+1 s` |
| 后退 | `Shift+Left` | `-1 s` |
| 快进 | `Right` | `+5 s` |
| 后退 | `Left` | `-5 s` |
| 加速 | `Ctrl+Right` | `+0.1 倍` |
| 减速 | `Ctrl+Left` | `-0.1 倍` |
| 恢复速度 | `S` | `1.0 倍` |
| 全局快捷键 | `Ctrl+Alt+F12` |  |

长按快进或后退快捷键可连续调整字幕进度，
打开全局快捷键可以在sz播放器里同时控制视频和字幕。

## 设置

设置界面支持：

- 自定义快捷键和参数
- 添加或删除快捷键规则
- 调整背景颜色和透明度
- 保存当前设置为默认
- 重置设置

前两条快进规则不可删除，分别控制界面上的快进和后退按钮。

## 注意

快捷键为全局快捷键。即使正在使用浏览器或其他软件，SRT Player 也会响应。

建议字幕文件使用 UTF-8 编码。
